# Examples

## Button
Input:
- Context: Export screen for monthly invoices
- Component: button
- User goal: download the invoice CSV

Output:
1) Primary: Download CSV
2) Short: Download
3) Alternatives: Export CSV; Download file
4) Rationale: Uses a clear verb + object tied to the immediate action.

## Form help text
Input:
- Context: Invite teammate modal
- Component: help_text
- User goal: enter a valid email

Output:
1) Primary: Use a work email, like name@company.com
2) Short: Example: name@company.com
3) Alternatives: Enter an email address (e.g., name@company.com)
4) Rationale: Adds a concrete example to prevent formatting errors.

## Error message
Input:
- Context: Sign-in form
- Component: error
- User goal: sign in successfully
- Problem: password is wrong

Output:
1) Primary: That password doesn’t match. Try again, or reset your password.
2) Short: Incorrect password. Try again.
3) Alternatives: Password not recognized. Try again or reset it.; Wrong password. Try again.
4) Rationale: States the issue and offers a clear recovery path.

## Empty state
Input:
- Context: Devices page for a new account
- Component: empty_state
- User goal: start tracking devices

Output:
1) Primary: No devices yet. Add your first device to start tracking assignments.
2) Short: No devices yet. Add one to get started.
3) Alternatives: You haven’t added any devices. Add a device to begin tracking.; Nothing here yet. Add a device.
4) Rationale: Explains why it’s empty and points to the next action.
